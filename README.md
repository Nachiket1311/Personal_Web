## 🤖 Multi-Cursor AI Agent Swarm (CursorSwarm)

This portfolio features an interactive **8-Agent Multi-Cursor Swarm** powered by `cursor-swarm.js`. Upon visiting the website:

1. **8 Autonomous Agents Spawn**:
   - 🟩 **`ARCHITECT`** — Structural layout and page hierarchy
   - 🟪 **`FRONTEND`** — Interactive UI components and buttons
   - 🟨 **`DESIGNER`** — Visual styling and container frames
   - 🟦 **`ENGINEER`** — Logic, frameworks, and architecture
   - 🟪 **`TYPIST`** — Letter-by-letter typing and text writing
   - 🟧 **`MEDIA`** — Image scanning and graphic rendering
   - 🔷 **`BUILDER`** — Component placement and copy-paste replication
   - 🟥 **`SYSTEM`** — Orchestration, build timing, and verification
2. **Adaptive Auto-Scroll**:
   - The webpage smoothly scrolls down automatically, adjusting speed based on active agent workload so visitors can watch each section being drawn, typed, and assembled in real-time.
3. **Smooth Return to Top**:
   - Once all sections are built and the footer is reached, the page pauses for celebration and smoothly glides back up to the top, presenting the complete, fully interactive portfolio.
4. **Interactive Floating Control Pill**:
   - Features real-time agent build indicators, auto-scroll `Pause/Resume`, `Speed (0.5x / 1x / 2x)`, `⬆ Top`, and `🔄 Replay` controls.
   - Touching the mouse wheel or mobile screen instantly transfers manual scroll control to the user.

## 🚀 Running Locally

You can serve this static site using any local web server:

```bash
# Clone the repository
git clone https://github.com/Nachiket1311/Personal_Web.git
cd Personal_Web

# Start local server with Python
python3 -m http.server 8000
```

Navigate to `http://localhost:8000` in your web browser.
